Excerpts of UniMorph's Spanish, Polish, Russian, German and Greek files (https://unimorph.github.io), a few verbs each and
four Polish nouns (ptak, stół, but, rodzic), two Russian (собака, мальчик), four German (Hund, Frau, Haus, Eltern) and two
Greek (γυναίκα, βιβλίο), for the Forms tests. UniMorph is drawn from English Wiktionary, under CC BY-SA 3.0
(https://creativecommons.org/licenses/by-sa/3.0/). UniMorph's only querer is the noun (el querer),
which the tests use as a verb that isn't found.
