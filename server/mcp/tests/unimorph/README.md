Excerpts of UniMorph's Spanish, Polish and Turkish files (https://unimorph.github.io), a few verbs each, for
the Forms tests. UniMorph is drawn from English Wiktionary, under CC BY-SA 3.0
(https://creativecommons.org/licenses/by-sa/3.0/). UniMorph's only querer is the noun (el querer),
which the tests use as a verb that isn't found.
Turkish is yapmak's positive statements only (POS and DECL, without the necessity forms and the
odd double tenses), the rows the Forms table reads.
