Pages from kaikki.org's extract of Polish Wiktionary (https://kaikki.org, made with Wiktextract), cut
down to each entry's word, part of speech and forms, for the Forms tests: czas, which UniMorph's
older extract lacks, and para, whose first noun ("steam") has no plural and whose next ("couple")
does. Wiktionary's text is under CC BY-SA (https://creativecommons.org/licenses/by-sa/4.0/).

Russian, German and Greek pages (тьма, воздух, Haus, χώρα, παιδί, δρόμος) come from the same extracts, cut down the same
way. The Russian ones keep what the real pages hold that the code has to skip: stress marks, a romanized twin of each form
(marked with a diamond), a block of dated spellings, and a partitive.
